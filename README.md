# VendorCAD marketing prototype

Static GitHub Pages export of the VendorCAD (FormForge) competitive-structure prototype, based on a ditto.site clone of DriveWorks.co.uk and rebranded for VendorCAD.

**Live:** https://appvantixai.github.io/vendorcad-driveworks-reference/

This is a design/reference prototype — not the production VendorCAD marketing site.

## Local

```bash
npm install
npm run build
npx serve out -l 3002
```

## GitHub Pages build

```bash
GITHUB_PAGES=1 npm run build
```
